Firebase Realtime Database
設定手順：① console.firebase.google.com でプロジェクト作成 → ② 「Realtime Database」を作成（テストモードでOK）→ ③ ルールタブに {"rules":{".":{"read":true,"write":true}}} を貼り替えて「公開」（テストモードは30日後に動かなくなるため、これで恒久化）→ ④ プロジェクト設定 →「マイアプリ」→ ウェブアプリ（</>）を追加して firebaseConfig を取得 → ⑤ 貼り付けて「接続する」。
社員に設定させたくない場合：⑤のconfigをこのHTML内の「CR_FB_PRESET」の行に貼った上で配布すれば、開くだけで自動接続されます。
Googleスプレッドシート連携（Google Apps Script）
セットアップ手順（約5分）
  1. Googleスプレッドシートを新規作成（予約データの保存先になります）
  2. メニュー「拡張機能」→「Apps Script」を開く
  3. 既存コードを消し、下のコードを全て貼り付けて保存
  4. 「デプロイ」→「新しいデプロイ」→ 種類：ウェブアプリ / 実行ユーザー：自分 / アクセスできるユーザー：全員
  5. 「デプロイ」→ 承認を実施 → 表示されたURL（…/exec）を上の欄に貼り付けて接続
  6. カレンダー連携も使う場合：同じURLでOK。承認時にカレンダーへの権限を許可してください
  7. 以前のGASコードから更新する場合：コード貼り替え後、「デプロイ」→「デプロイを管理」→ 編集 →「新バージョン」→「デプロイ」（URLは変わりません）

かんたん操作ガイド

      
    

    

      
予約を登録するタイムテーブルの空きマスをクリック（PCはドラッグで範囲選択）→ 内容を入力 →「保存」。「＋ 新規予約」ボタンからでも登録できます。

      
変更・キャンセルする予約ブロック、または「アイテム別」タブの行をクリック → 編集するか「キャンセル（削除）」。

      
重複チェック同じ対象・同じ時間帯の予約は、登録時にエラー表示されます。

      
色分けで登録外出／ウェブ打合せ／来客／所内打合せ／休暇／事務所行事／出勤日／その他 の8種類から選ぶと、タイムテーブルが色で分かれます。

      
行（予約対象）を増やす「設定」→「基本」で「＋ 対象を追加」、または名前のリストを「まとめて貼り付け」の欄に1行に1件ずつ貼り付けて一括作成できます。

      
日付を移動する左のミニカレンダーや「前日／本日／翌日」で移動。上部タブ「カレンダー」で月間表示に切り替えられます。

      
スマホ・他のPCと共有する「設定」→「データ同期」から Firebase または Googleスプレッドシートに接続すると、全端末で同じ予約状況が見られます。Googleカレンダーとの双方向同期も同じ画面で設定できます。
